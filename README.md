# Medal Bypass

**Modern watermark-free downloader for Medal.tv clips.**  

A minimalist, high-performance web application designed to fetch raw MP4 files directly from Medal.tv servers, bypassing watermarks and speed restrictions.

## Tech Stack

| Layer | Technology |
|---|---|
| **Framework** | Next.js 14 (App Router) |
| **Styling** | Tailwind CSS (Minimalist Dark Mode) |
| **Language** | TypeScript |
| **Icons** | Lucide React |

## Features

- **No Watermarks:** Downloads high-quality MP4 files directly from source servers.
- **Minimalist UX:** "Quiet Luxury" aesthetic with glassmorphism and smooth transitions.
- **Performance:** No ads, no popups, only the core download functionality.
- **SEO Optimized:** Dynamic sitemap, OpenGraph tags, and robots.txt pre-configured.

## Getting Started

1. **Clone:** `git clone https://github.com/hugotakeda/MedalBypass.git`
2. **Install:** `npm install`
3. **Development:** `npm run dev`
4. **Build:** `npm run build`

## Project Structure

- `src/app/`: Next.js application logic and routes.
- `src/components/`: Reusable UI components.
- `src/lib/`: Core download utilities and API handling.
